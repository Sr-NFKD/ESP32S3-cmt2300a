# 射频管家 BSP

目标：ESP32-S3FN4R2；ESP-IDF 5.5.4；LVGL 9.2.2（通过组件管理器固定版本）。

## 工程分层

| 目录 | 职责 |
| --- | --- |
| `main/` | 固件入口，只调用应用启动函数 |
| `components/app/` | 初始化顺序、定时器、界面与业务协调；拆分电源管理、射频控制、串口命令 |
| `components/bsp/` | 板级硬件：供电、背光、按键、显示、电池、CC1101、休眠 |
| `components/rf_protocol/` | 不依赖硬件的波形编解码，以及界面/服务共用的数据类型 |
| `components/rf_service/` | 扫频、RMT 采集/回放、信号确认、信号库操作 |
| `components/user_data/` | NVS 设置、信号资料、升级后资料保留/清理策略 |
| `components/debug_ota/` | Wi-Fi 热点、管理网页、固件升级；调用独立存储组件 |
| `components/rf_ui/` | 设备与电脑预览共用的 LVGL 界面 |
| `simulator/` | Windows 预览入口和构建脚本 |
| `tests/` | 不依赖实板的行为回归测试 |

具体文件职责、依赖方向和修改入口见 [工程架构](工程架构.md)。双击 `simulator/preview.cmd` 可打开预览，方向键/回车模拟五维按键。

## 引脚

| 功能 | GPIO |
| --- | --- |
| 屏幕与射频公共供电使能，高电平有效 | 48 |
| 电池电压采样（33kΩ 上臂 / 10kΩ 下臂） | 17 |
| LCD LED / RES / DC | 15 / 14 / 10 |
| LCD MOSI / SCLK / CS | 11 / 12 / 13 |
| A07 GDO0 / CS / SCLK / MOSI / MISO / GDO2 | 9 / 8 / 7 / 6 / 5 / 4 |
| 按键 上 / 右 / 左 / 中 / 下 | 1 / 2 / 18 / 16 / 3 |

按键内置上拉，按下接地。固定 2 ms 连续稳定后更新按键状态，不提供消抖设置菜单；按键掩码按上、右、左、中、下对应 bit0～bit4，支持读取同时按下状态。LVGL keypad 单次报告一个键，按此顺序优先；界面使用 group 时需将 `bsp_keypad_get()` 绑定到应用创建的 group。

## 上电与显示

先关闭背光、取消两个 SPI 片选并保持屏幕复位，再拉高 GPIO48；等待 20 ms 后初始化外设。该供电稳定等待是初始值，实板测量后可调整。

屏幕为 CL10CK338-8A，ST7735S，原生 80×160；默认横屏 160×80。初始化和 Gamma 参数移植自桌面“射频管家/屏幕相关”厂家资料，使用例程方向 3（90°），MADCTL=0xA8，横屏偏移 x=1、y=26。若安装方向相反，可将 MADCTL 改为例程方向 2 的 0x68，仍使用横屏偏移。

屏幕使用 SPI2、目标 30 MHz、RGB565，实际时钟由 SPI 分频器决定。LVGL 使用两个内部 DMA 缓冲（各 160×20×2=6400 字节，共 12.8 KiB），提交传输后立即返回，在另一个缓冲中绘制；LVGL 的 flush-wait 回调在下一次传输或重用缓冲前等待 DMA 完成，ISR 只发送信号量。颜色字节序在刷新中转换。LVGL tick 从 `esp_timer` 获取，全部 UI 操作和 `lv_timer_handler()` 由 main 同一任务执行；后续其他任务访问界面需统一交给该任务或增加互斥保护。

接收页可选自动扫描、433.92 MHz、315 MHz 或 318 MHz。CC1101 解调 OOK/ASK 后由 GPIO4（GDO2）接入 ESP32-S3 RMT，以 1 μs 单位采集高低电平时序；空闲间隔用于分帧，弱于 -85 dBm 的 RAW 候选被过滤，固定码要求完整同步和重复确认。当前可解码常见 1:3 脉宽 PWM 固定码（8～32 位，含 1:31 同步间隔）；其他波形以 RAW 保存，用户按中键确认。两次一致的解码帧才标记为完整码。RAW 发送受 300 ms 波形总长上限及五次重复限制；固定码可在信号详情里选择“发射信号”，改键码后按协议重新生成波形。此功能覆盖常见固定码，不保证滚动码、加密码或其他调制协议能重放。

发射页浏览已保存的信号，可选择发射或删除；干扰页提供被动 RSSI 和信道占用率监测，自动扫描时在 13 个 CC1101 支持的预设频点间切换。设备只统计信号强度，不发射压制信号。

按键采用 GPIO 双边沿中断：ISR 只通知独立按键任务，任务逐键进行固定 2 ms 消抖，消抖期间每 1 ms 复查，稳定后休眠等待中断。确认后的按下/松开状态放入 32 项队列并唤醒界面任务，界面先按顺序消费事件，再运行 LVGL；每个按键事件产生的射频请求立即提交，不再等待 50 ms 同步周期。若界面长时间阻塞导致队列满，丢弃最旧事件并记录警告，保留最新松开状态避免卡在长按。中断和按键任务均不调用 LVGL。`esp_timer` 仍每 1 ms 唤醒界面，背光同步为 10 ms，电池更新为 500 ms，亮度长按和动画由 LVGL 定时器执行。`python tests/check_buttons.py` 验证真实消抖及队列逻辑；响应时间仍需实板测量。

“调试”下提供“开始调试”按钮，中键或鼠标点击后，后台启动 `RF-Manager` 热点（密码 `rfmanager123`）与 `http://192.168.4.1` 固件升级网页。显示“已开启”后再次按下可关闭热点和网页。界面每 50 ms 同步状态，返回菜单不关闭已启动热点。网页支持信号重命名、键码编辑、删除、单个/批量 JSON 导出；升级默认保留信号、不重置设置，新固件确认成功启动后才执行清理。亮度停调一秒后持久化。首次改用双 OTA 分区需串口完整烧录；网页上传文件为 `ESP32S3_A07_CC1101.bin`，详细流程见 `components/debug_ota/README.md`。

GPIO15 背光采用低电平点亮，30 kHz、11 位 PWM。界面亮度 1%～100% 分为 100 级，线性对应引脚高电平占空比 100%～50%：1% 最暗，100% 最亮。通过 LEDC 输出反相实现，内部计数为 0～1024，避免使用溢出的 2048 计数。内部接口 0 表示关闭背光；启动时保持高电平，首帧完成后恢复保存的亮度（默认 70%）。`python tests/check_backlight.py` 验证全部 100 级映射与边界。

## 射频底层范围

射频使用 SPI3、1 MHz、模式 0，软件控制 CS，以便先等待 MISO/SO 的 CHIP_RDYn 变低再传输。初始化执行 SRES、读取 PARTNUM/VERSION；失败返回错误且释放射频 SPI 资源。就绪等待上限 10 ms，未接模组不会无限卡死。初始化成功停留在 IDLE，不自动发射或进入接收。

`components/rf_service` 已接入 OOK 收发、RMT DMA 采样/回放、固定码识别、RAW 保存、信号库操作和 RSSI 被动检测。GDO2/GPIO4 接收、GDO0/GPIO9 发射。固定频点提供 315、318、433.92 MHz；自动模式快速轮扫 13 个预设，进入 RX 后至少等待 2 ms，依据每频点自适应本底和绝对门限命中锁频，最多采集 1 秒；确认保存后继续轮扫。切频复用各频点 FSCAL 校准结果，超过 10 秒重校准。定时器唤醒任务执行射频操作，详见使用说明和 THIRD_PARTY_NOTICES.md。协议边界与操作见使用说明。

A07-S433A10S2a 手册给出的模组频段为 387～464 MHz；CC1101 芯片频段包括 300～348 MHz 和 387～464 MHz。315 MHz 不在此 433 MHz 模组的标称频段，348～387 MHz 也不在芯片列出的频段内。后续 315/433 MHz 切换或试验性偏频应结合匹配网络、天线、PLL 校准和实测结果处理，当前没有把 315～433 MHz 当作保证连续覆盖范围。

## 构建与上板验证

在 ESP-IDF 终端执行：

```text
idf.py build
idf.py -p COM端口 flash monitor
```

新复制工程且没有 `sdkconfig` 时，先执行 `idf.py set-target esp32s3`。

首次下载依赖需要联网。`sdkconfig.defaults` 配置 ESP32-S3、4 MB Flash、Quad PSRAM 40 MHz 和 1 kHz FreeRTOS tick；PSRAM 实际容量由启动时检测。PSRAM 接线、供电和芯片型号仍需实板确认。

`python tests/check_panel_reference.py` 可核对移植后的初始化/Gamma 参数与桌面厂家文件的一致性，并检查引脚无重复及横屏偏移。资料移动后通过参数指定原始 Gamma2.2.txt 路径。

一级菜单每个选项占一页，依次为接收、发射、干扰、调试、设置，左侧带对应图标，底部显示页码。上/下键翻页，约 320 ms 上下滑动，单次按下切换一次，首尾循环；同时按上下不翻页。中文菜单采用 32 像素 Noto Sans SC 专用子集字体，图标 36 像素，电压与页码缩小到 10 像素；菜单显示区域高 48 像素。

采用深灰渐变背景和圆角菜单卡片；接收为薄荷绿、发射为暖橙、干扰为珊瑚红、调试为紫色、设置为银灰。设置二级菜单使用金黄、浅紫、嫩绿、粉红、浅蓝区分功能，图标、卡片描边和页码相互呼应，电池保持中性灰白。

在“设置”上按中键进入二级菜单，依次为亮度、休眠、唤醒、重置、关于，各占一页，上下切换并带滑动动画，首尾循环，左键返回一级菜单。当前只有亮度接入实际功能，其余为菜单入口，不执行休眠、唤醒、重置等动作。

在“亮度”上再按中键进入调节。上键增加、下键减少，短按每次 1%，范围 1%～100%，实板立即更新背光 PWM。按住 400 ms 后开始连续调节，固定每 120 ms 增减 1%，不再继续加速（实际更新受主循环帧率影响）。松开、同时按上下或离开调节页立即停止，反向按键重新计时。左键逐级返回，中键结束调节回到亮度菜单。默认亮度 70%，停止调节一秒后保存到 NVS。

右上角电池图标内显示电压，应用通过 `rf_ui_set_battery_mv()` 提供毫伏值，0 表示未知。实板使用 GPIO17 ADC 单次采样和曲线校准，每次平均 16 个校准后的样本，每 500 ms 更新一次；上电先立即读取一次。初始化或读取失败时显示 `--.--V`，失败原因写入日志。GPIO17 属于 ADC2，后续 Wi-Fi 功能需处理读取资源冲突，当前代码已按错误返回值处理。

电池为单节锂电池（标称 3.7V，满电 4.2V）。接法：电池正极 → 33kΩ → GPIO17 中点 → 10kΩ → GND；GPIO17 与 GND 之间建议并接 100nF 电容。不要把电池正极直接接 GPIO17。分压为 10/43，满电采样点约 0.977V；使用 ADC 2.5 dB 衰减和 4.3 倍电压换算。电阻常开消耗约 98µA（满电时）；实测校对后可在 `bsp_board.h` 中调整电阻参数或 `BSP_BATTERY_SCALE_PPM`。

电脑预览显示模拟值 `3.85V`，不代表实测数据。

上板验证：

1. 测量 GPIO48 上电后为高，屏幕和模组电源正常。
2. 屏幕默认显示“接收 / 1 / 5”，横屏文字正常、四边无裁切；从日志检查 CC1101 的 PARTNUM/VERSION 或识别错误。
3. 上/下键应正确切换菜单；逐个按下上、右、左、中、下，日志掩码应分别为 01、02、04、08、10，松开为 00；组合按键掩码为对应位之和。
4. 通过调用背光接口验证 0、25、70、100 的亮度，并用示波器核对 GPIO15 的约 30 kHz PWM。
5. 按使用说明验证接收、保存、网页改名/改码、发射、删除、被动检测和 OTA。

编译只能验证代码和链接；上述供电、显示方向、色彩、背光和射频芯片识别需下载到硬件确认。

菜单切换统一使用 LVGL 动画：上下翻页为 320 ms 纵向滑动与淡入淡出，进入子页面为向左滑动、返回为向右滑动，调试状态变化为 280 ms 淡入淡出。滑动使用 ease-out 曲线，淡入淡出使用 ease-in-out 曲线。页脚同步淡入，电池图标保持固定；快速连续按键以最新目标为准。亮度数值直接更新，保持长按调节响应。

高帧率配置：CPU 240 MHz，LVGL 默认刷新周期 5 ms，预览保持相同周期。5 ms 只是调度目标，并非测得 200 FPS；静态页面仅在内容变化时刷新。实际帧率受绘制、SPI 实际时钟及屏幕扫描速度限制。30 MHz 超过 ST7735S 通用数据手册约 15 MHz 的写时钟规格，需实板长时间验证；如有花屏可降低 `BSP_LCD_SPI_HZ`。`python tests/check_display_pipeline.py` 验证真实刷新函数的异步提交、完成等待、提前中断与提交失败处理，不测量硬件帧率。
