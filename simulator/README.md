# Windows LVGL 预览器

信号库每页显示三个信号，上下键移动高亮选择，跨页自动翻页并首尾循环，高亮以 180 ms 动画移动。条目使用“MHz频率_编码”（例如 `433.92_12AB01`）；实板新保存的已解码信号也使用该名称。未解码信号显示 RAW 标记和编号。单击条目在后台发送该信号，屏幕停留在列表，不显示发送状态，右击条目打开其发射/删除操作菜单；键盘回车直接发送，右方向键打开操作菜单。删除需要确认；操作菜单中的发送也在后台执行，左键返回列表。

双击 `preview.cmd`：先编译共享界面，再弹出预览窗口。以后修改 `components/rf_ui/rf_ui.c` 后再次双击即可查看。

- 与 ESP32 使用同一份界面代码和 LVGL 9.2.2。
- 逻辑分辨率 160×80，窗口按 4 倍放大（640×320），保持实际布局。
- 预览键盘扫描采用 5 ms LVGL 定时器；翻页动画和亮度长按也由 LVGL 定时器驱动。实板电池采样与显示刷新采用 500 ms 定时器，电脑电压仍为固定模拟值。
- 点击预览窗口使其获得焦点；上/下键切换菜单，单次按下翻一页，首尾循环，同时按上下不翻页。回车模拟中键，左方向键返回，右方向键在信号库打开所选信号的操作菜单。
- 每个选项占一页：接收、发射、干扰、调试、设置；左侧显示功能图标，底部显示页码；上/下切换采用约 180 ms 的滑动动画。
- 右上角电池图标内显示电压；电脑预览固定演示 3.85V。
- 在“设置”上按回车进入二级菜单，再按回车调节亮度；上/下键短按增减 1%，范围 1%～100%。按住 400 ms 后开始连调，固定每 120 ms 增减 1%，不继续加速；松开或同时按上下停止，左键逐级返回。电脑展示亮度设置值，实板实际控制 PWM；当前不保存到 Flash。
- 设置二级菜单为“亮度、休眠、唤醒、重置、关于”，上下翻页、首尾循环并带动画。除亮度外，其余目前为菜单入口。实板按键消抖固定为 2 ms，不提供调节菜单。
- 关闭窗口退出。只预览界面，不连接射频模组。
- 在“调试”上按回车进入“开始调试”，再按回车或鼠标点击按钮模拟启动。电脑预览只模拟“启动中/已开启”状态，不启动真实 Wi-Fi 或固件升级服务。

工具为便携版 w64devkit 2.6.0，放在 `.tools/w64devkit`，仅修改启动脚本当前进程的 PATH，不修改系统设置。缺少工具时脚本自动下载、核对 SHA256 并解压；首次启动需联网。

如果将工程复制到另一台电脑：先在 ESP-IDF 环境中构建一次以获得 `managed_components/lvgl__lvgl`，然后双击启动脚本。也可以从 https://github.com/skeeto/w64devkit/releases/tag/v2.6.0 手动下载 x64 包，解压到 `.tools`，使 `.tools/w64devkit/bin/gcc.exe` 存在。包 SHA256 为 `bb212f0012a9324b8cf4104a76c07199d9c17607b4c5755632108d0432359beb`。

只编译：`powershell -NoProfile -ExecutionPolicy Bypass -File simulator/preview.ps1 -BuildOnly`。

自动验证：运行 `simulator/build/rf_preview.exe --smoke-test`；检查正常启动画面、五页名称与页码、上下翻页、首尾循环、按住不重复翻页、同时按键、快速连续翻页，以及电压格式。渲染 `preview-1.bmp`～`preview-5.bmp` 和动画中间帧 `preview-transition.bmp` 供检查布局。

预览器采用 LVGL 内置 Windows 驱动；依赖原有 LVGL 源码，不需要 SDL。桌面程序与 ESP32 固件分别构建，电脑预览不能验证屏幕接线、PWM、射频或供电。

0.2.0 新页面：接收频段选择、等待/保存、信号库、发射/删除确认、被动占用检测。PC 模型会在开始接收后约 1.2 秒模拟收到 12AB01；保存后可演示发射/删除，不读写实板 Flash，也不进行真实射频活动。实际板端使用独立 rf_service 工作任务。
